A pays B while B pays A

What it does

Admin account approval, deposits, withdrawals, transfers, beneficiaries and monthly PDF statements. Deployed live with Swagger API docs.

Engineering decisions

  • Transfers run in a single @Transactional method so a failure never leaves half a transfer.
  • Row-level locking with ordered locks avoids deadlocks.
  • An Idempotency-Key prevents double payments.
  • Verified with multi-threaded JUnit tests.
